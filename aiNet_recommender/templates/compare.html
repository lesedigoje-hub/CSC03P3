Population-Level & Temporal Metrics

These metrics look beyond a single recommendation list, and are computed for both aiNet and kNN so they can be compared directly. Catalog coverage, Gini coefficient and entropy of exposure are derived from running both aiNet (fresh, no carried-over population) and kNN for the same sample of existing users, and combining what each algorithm showed them. Temporal diversity simulates several rounds of the current session, adding the same synthetic ratings between rounds to both algorithms, and measures how much each one's recommendation list changes round to round — both by literal movie ID and by the underlying genre-vector profile, since these can disagree. aiNet carries its evolved population forward between rounds as usual; kNN has no equivalent persistent state, so it is recomputed fresh from the ratings available at each round.

Both of these are more expensive to compute than the table above, so they only run when you submit the form below.

ID-level answers whether the literal movie IDs shown changed between rounds. Vector-level answers whether the underlying genre-vector profile actually moved, independent of which specific movie ID represented it. A high ID-level score alongside a flat vector-level score means different titles are being shown from the same narrow genre neighbourhood, round after round — worth checking for either algorithm. Also note kNN has no carried-over state between rounds, so its temporal diversity reflects only the new ratings added each cycle, while aiNet's also reflects inertia from its evolving population.
